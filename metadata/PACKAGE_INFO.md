# Package information

This archive contains the computational materials required to reproduce the numerical analyses and figures for the study of absorbing margin-liquidation cascades.

Included materials:
- analytic and simulation source code,
- fixed random seeds,
- generated numerical tables and trajectory arrays,
- expected numerical outputs for validation,
- generated and expected figure files,
- environment specifications,
- automated validation scripts.

The package contains no empirical market data. All numerical experiments are theoretical and dimensionless.
